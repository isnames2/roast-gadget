A make.fun entry for [One-Line Roast: The Gadget You Use Every Day](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610).

`main.py` (pure Python standard library) writes one roast line to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> My password manager locked me out of my own account, so now I pay a program to forget my password for me.

The roast targets a password manager app: it exists to remember passwords, yet here it locked its owner out -- the irony is the punchline.
